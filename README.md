# Password Strength Analyzer

A beginner Python cybersecurity project that evaluates password characteristics and provides basic feedback about password strength.

## Current Features

- Checks password length.
- Detects uppercase letters.
- Detects lowercase letters.
- Detects numbers.
- Detects special characters.
- Displays a password analysis report.

## Technologies

- Python 3
- Python standard library

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python password_analyzer.py
```

## Concepts Practiced

- Variables and data types
- User input
- Conditional logic
- For loops
- Boolean values
- Built-in functions such as `any()` and `len()`
- Python modules
